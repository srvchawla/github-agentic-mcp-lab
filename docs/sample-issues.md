# Workshop sample issues

These open issues seed the starter repository with realistic activity for the
daily-status workflow and GitHub MCP exercises. Issue descriptions include
acceptance criteria or example TypeScript where useful.

| Issue | Type | Exercise |
|---|---|---|
| [#1 Add `deleteTask` to `TaskStore`](https://github.com/srvchawla/github-agentic-mcp-lab/issues/1) | TODO / enhancement | Implement a task-store feature and persistence tests. |
| [#2 Add completion filters to `TaskStore.list`](https://github.com/srvchawla/github-agentic-mcp-lab/issues/2) | TODO / enhancement | Extend an existing API while preserving its current behavior. |
| [#3 Reject blank task titles](https://github.com/srvchawla/github-agentic-mcp-lab/issues/3) | TODO / bug | Add input validation and edge-case tests. |
| [#4 Document the task-store API](https://github.com/srvchawla/github-agentic-mcp-lab/issues/4) | Documentation | Write a short usage example based on the current API. |
| [#5 Decide how priorities should affect task ordering](https://github.com/srvchawla/github-agentic-mcp-lab/issues/5) | Question | Discuss behavior and recommend a testable default. |

Issues #1–#3 have the `todo` label; all five have the `demo` label. When
running a fork, create equivalent issues there because GitHub does not copy
issues when a repository is forked.
