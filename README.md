| Lab | Topic | Time |
|-----|-------|------|
| [0](labs/00-setup.md) | Setup (before class) | - |
| [1](labs/01-gh-aw-first-workflow.md) | First agentic workflow | 15 |

| [4](labs/04-stretch-custom-mcp-server.md) | Build an MCP server (stretch) | 20 |
